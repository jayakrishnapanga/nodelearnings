The non-blocking I/O is handled by the OS through libuv, while blocking tasks use the thread pool. But the user is focusing on the non-blocking part here.

|  [ 2. DNS lookup job ]     |  → Worker 2 picks up
|  [ 3. crypto.pbkdf2 job ]  |  → Worker 3 picks up
|  [ 4. fs.stat job ]        |  → Worker 4 picks up
